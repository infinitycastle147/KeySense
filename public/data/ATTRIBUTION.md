# Data Attribution

The word lists, quotes, and keyboard layout definitions in this directory are
copied from [monkeytype](https://github.com/monkeytypegame/monkeytype), which is
licensed under **GPL-3.0**.

Because these files are redistributed here, KeySense is also licensed under
GPL-3.0 (see `/LICENSE` at the repo root).

## Files

| Path | Source |
| --- | --- |
| `languages/*.json` | `frontend/static/languages/` |
| `quotes/english.json` | `frontend/static/quotes/` |
| `layouts/*.json` | `frontend/static/layouts/` |

No monkeytype source code is used in this project — the typing engine, analysis
pipeline, and UI are original. Only these data files are reused.
